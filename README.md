A program that writes a one-sentence piece of the best advice ever received to `/output/entry.txt` for make.fun's "The Best Advice I Ever Got" bounty.

The winning line:

> My dad said a promise made when you're tired is still a promise, so I stopped saying yes at midnight and started keeping the ones I'd already given.

A dad's rule about promises made when tired, and the midnight habit it changed: stop saying yes at midnight, start keeping the yeses already given.

## Run it

```sh
python3 main.py
```
